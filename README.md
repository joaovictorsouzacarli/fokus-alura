# Fokus - Temporizador de Produtividade

O Fokus é uma aplicação web de temporizador estilo Pomodoro, desenvolvida durante o curso de JavaScript da **Alura**. O objetivo é ajudar o usuário a alternar entre períodos de foco e descanso (curto ou longo), com uma interface que muda de contexto visual e sonoro.

## 🛠️ Tecnologias utilizadas:
* **HTML5** (Estrutura semântica)
* **CSS3** (Estilização com variáveis e responsividade)
* **JavaScript** (Manipulação de DOM, eventos e objetos de Áudio)

## ✨ Funcionalidades:
* Alternância de contextos: Foco, Descanso Curto e Descanso Longo.
* Alteração dinâmica de textos e imagens conforme o modo selecionado.
* Play/Pause com efeitos sonoros.
* Ativação/Desativação de música de fundo (Lo-fi).
* Interface responsiva para dispositivos móveis.

## 🎓 Aprendizados:
Este projeto foi fundamental para praticar o método `setInterval()`, manipulação de classes no CSS via JS e o uso do objeto `new Audio()`.
